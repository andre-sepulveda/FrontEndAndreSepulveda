# Quadro de Tarefas

Gerenciador de tarefas acadêmicas — projeto da disciplina de Desenvolvimento Frontend (2026.2), Profª Marianne Lacerda Dutra Theodoro.

## Sobre o projeto

Aplicação de quadro de tarefas com quatro colunas de status (A Fazer, Em Andamento, Em Revisão, Concluído), com busca por título, filtros por status e prioridade, e ordenação por prazo. Os dados são carregados via `fetch` de um arquivo `dados.json`.
